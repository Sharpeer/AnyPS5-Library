# Sécurité

## Versions suivies

Seule la dernière version publiée reçoit des corrections.

## Signaler une faille

Ne crée pas de ticket public pour une faille de sécurité. Utilise le signalement privé de GitHub : onglet « Security » de ce dépôt, puis « Report a vulnerability ».

Indique la version d'AnyPS5 Library, la version de Windows, et les étapes qui montrent le problème. Ne joins aucun fichier de jeu.

## Contrôler un téléchargement

Télécharge l'installateur seulement depuis les [versions de ce dépôt](https://github.com/Sharpeer/AnyPS5-Library/releases). Chaque version publie l'empreinte SHA-256 de son installateur. La mise à jour intégrée contrôle cette empreinte avant d'installer.

L'installateur n'est pas signé numériquement : Windows SmartScreen peut afficher un avertissement.
